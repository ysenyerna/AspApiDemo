## ASP API Demo
Simple ASP application to demonstrate an API Controller and JavaScript fetch calls. 
### Explanation
This program uses an API controller called `PostsController` which allows posts to be added and read. When you open the
home/dashboard, the Razor page automatically adds some posts (this is for testing as otherwise there would be no posts), 
then reads and displays them using JavaScript fetch calls. It retrieves the post information from the API and displays
the total number of posts and recent post titles.
